# Ethical Disclaimer

osint-mini-toolkit is an educational and defensive research tool.

Use it only when you have a lawful basis and authorization to investigate the
target, file, account name, or domain. Do not use this project for harassment,
credential attacks, bypassing access controls, stalking, unlawful surveillance,
high-volume scanning, or any activity that violates a platform's terms or local
law.

The default username checker performs conservative public profile URL checks and
uses rate limiting. The domain module performs basic DNS, WHOIS, and common-port
checks intended for learning and authorized asset review.
